# Calculadora Electroquímica

## Descripción
Aplicación desarrollada en Java para el análisis de celdas electroquímicas mediante la ecuación de Nernst.

## Funcionalidades
- Selección de 15 electrodos.
- Validación de símbolos químicos.
- Identificación del ánodo y cátodo.
- Cálculo del potencial estándar de celda.
- Aplicación de la ecuación de Nernst.
- Identificación de oxidación y reducción.
- Presentación de semirreacciones.
- Análisis de espontaneidad.
- Cálculo de la reacción inversa.
- Validación de datos y manejo de excepciones.

## Tecnologías utilizadas
- Java
- IntelliJ IDEA
- Maven
- Git
- GitHub

## Ejecución
1. Descargar o clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Ejecutar OrdinariodeQuimica.java.
4. Ingresar los electrodos y sus concentraciones molares.

## Objetivo
Integrar la programación y la electroquímica mediante una herramienta computacional que facilite el análisis de celdas electroquímicas.
